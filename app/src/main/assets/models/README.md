# Bundled Whisper Model

`ggml-tiny.en.bin` is the English Whisper Tiny model distributed for
whisper.cpp.

- Source: https://huggingface.co/ggerganov/whisper.cpp
- SHA-256: `921e4cf8686fdd993dcd081a5da5b6c365bfde1162e72b08d75ac75289920b1f`
- Runtime use: offline, on-device transcription only

Model download and model switching are intentionally not implemented.
